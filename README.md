🎬 Movie Revenue Correlation Analysis  
A data‑driven exploration of what factors most strongly influence a movie’s gross earnings. This project applies correlation analysis techniques to uncover relationships between key variables in a movie dataset, such as budget, votes, and ratings.

🔍 Project Overview  
The goal of this analysis is to identify which features are most closely associated with a film’s financial success. By examining correlations among numeric attributes, the project highlights patterns that reveal how production budgets, audience engagement, and other measurable factors contribute to box‑office performance.
